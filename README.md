# Illustrator PDF 批量转曲脚本

一键批量将 PDF 说明书/画册中的所有文字创建轮廓（转曲），**3秒/份，无剪贴蒙版，直接覆盖原文件**。

## 功能亮点

- ⚡ 极速：20页说明书约3秒完成
- 🎯 完美：无剪贴蒙版，打开即可编辑
- 📦 批量：选择文件夹，自动处理所有 PDF
- 🔄 原样覆盖：不生成多余 AI 文件，原 PDF 直接更新
- 💰 免费：MIT 协议，随意使用、修改和分发

## 使用方式

1. 下载 `文件转曲.jsx` 脚本
2. 放入 Illustrator 脚本目录：`Presets\zh_CN\脚本\`
3. 重启 【Illustrator】
4. 点击菜单 `文件 → 脚本 → 文件转曲`
5. 在弹出的对话框中选择包含 PDF 的文件夹
6. 等待几秒，完成！

## 兼容性

- Illustrator 2024（中文版）
- Windows / macOS

## 原理

脚本模拟手动操作流程：全选（Ctrl+A）→ 创建轮廓（Ctrl+Shift+O）→ 存储（Ctrl+S），全程由 Illustrator 内核直接执行。
